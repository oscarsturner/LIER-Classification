# LIER-Classification

## How to use this data
We suggest using the document "Cleaned LIER Classifications.csv". This document contains a baseline classification for 10,451 MaNGA observations which have available data, plus other relevant information about their ionization morphlogies, and, for convenience, inclination angle, stellar mass, and magnitude measurements from the NASA-Sloan Atlas. This document does _not_ include objects without usable Marvin data. The example notebook in this repository demonstrates how to use this table both on its own and in conjunction with Marvin and the full MaNGA data. 

"FULL LIER Classifications.csv" contains the raw output from the classification pipeline. It includes different classifications used for quality assurance. These different classifications were made using (1) a lower signal-to-noise ratio cutoff, (2) a lower threshold fraction of LIER-like spaxels necessary to classify a region as LIER, and (3) a higher such threshold fraction. These classifications might be used to select, for example, galaxies which were classified as star-forming in the baseline classification and all three quality assurance classifications, or galaxies which have weaker LIER regions which only appear using the lower threshold fraction. Broadly speaking, differences between classifications tend to have to do with weaker outer LIER-like emission, which does not appear at the baseline SNR cutoff of 3 but does appear at the lower cutoff of 2; or which appears at the baseline LIER threshold fraction of 1/2 but not at the higher fraction of 3/5. 

## Classification Scheme
Details of the classification method will be released in a paper. Mostly, we follow Belfiore et al. (2016). Below is a broad overview:

With the advent of spatially resolved spectral data for galaxies, it is now possible to classify galaxies based on the distribution of their ionization lines. We use the \[SII\] BPT diagram and demarcation lines from Kewley et al (2001) to classify individual spaxels in the galaxy as having SF-like, Seyfert-like, or LIER-like emission. Galaxies where SF-like emission is visible at all effective radii are classified as SF. Galaxies which have a significant fraction of central Sy emission are classified as Sy. Galaxies which are dominated by LIER emission at the center but are star forming at outer radii are central-LIERs (cLIERs). Galaxies which have LIER emission at all radii are extended-LIERs (eLIERs). Galaxies with extraplanar LIER emission, or LIER emission only at outer radii, are outer-LIERs (outLIERs). Galaxies with a central equivalent width of H alpha below 1, or with too few pixels with a SNR above 3, are lineless. Mergers are flagged using Galaxy Zoo data from GZ DESI and classified as mergers. 

The code for these classifications is available in this repository.
